📋 Soal 1: Informasi Kali Linux

Apa itu Kali Linux?

Kali Linux adalah sistem operasi berbasis Linux yang dirancang khusus untuk penetration testing dan security auditing. Kali Linux dikembangkan oleh Offensive Security dan menyediakan lebih dari 600 tools untuk keperluan cybersecurity dan ethical hacking.

Versi: Kali Linux 2024.3
Basis: Debian Linux
Desktop: Xfce (default), GNOME, KDE
Lisensi: Open Source & Gratis

Sejarah Kali Linux

Kali Linux diluncurkan pada 13 Maret 2013 sebagai penerus BackTrack Linux. Berikut timeline pentingnya:

  • 2006-2012: Era BackTrack Linux
  • 2013: Peluncuran Kali Linux 1.0
  • 2016: Model Rolling Release (update terus menerus)
  • 2020: Default Non-Root User untuk keamanan
  • 2024: Kali Linux 2024.3 dengan tools terbaru

Fitur Utama

  • ✅ Lebih dari 600 security tools pre-installed
  • ✅ Open source dan gratis selamanya
  • ✅ Rolling release (always up-to-date)
  • ✅ Multi-platform (PC, VM, Cloud, Mobile)
  • ✅ Customizable sesuai kebutuhan
  • ✅ Live boot mode (tidak perlu install)
  • ✅ Dokumentasi lengkap

Tools Populer di Kali Linux

  • Nmap: Network scanning & mapping
  • Metasploit: Exploitation framework
  • Wireshark: Network protocol analyzer
  • Burp Suite: Web application security testing
  • Aircrack-ng: Wireless network testing
  • John the Ripper: Password cracking
  • Sqlmap: SQL injection testing
  • Hydra: Network login cracker

Kegunaan Kali Linux

  • Penetration Testing & Ethical Hacking
  • Security Auditing
  • Vulnerability Assessment
  • Digital Forensics
  • Network Security Testing
  • Web Application Testing
  • Pembelajaran Cybersecurity
⚠️ PERINGATAN: Gunakan Kali Linux hanya untuk tujuan legal seperti pembelajaran dan authorized testing. Penyalahgunaan dapat melanggar hukum!

⚙️ Soal 3: Cara Install Kali Linux

Persiapan

  • File ISO Kali Linux (dari kali.org)
  • USB Flash Drive minimal 8GB
  • Software Rufus atau Balena Etcher
  • Backup data penting

Spesifikasi Minimum

  • Processor: Intel i3 atau AMD equivalent
  • RAM: 2GB (8GB recommended)
  • Storage: 20GB (50GB recommended)

Langkah Instalasi

Step 1: Buat Bootable USB

  • Download dan buka Rufus atau Etcher
  • Pilih USB flash drive
  • Pilih file ISO Kali Linux
  • Klik "Start" atau "Flash"
  • Tunggu sampai selesai (5-15 menit)

Step 2: Boot dari USB

  • Restart komputer
  • Tekan F2/F12/Del saat booting
  • Masuk ke Boot Menu
  • Pilih USB sebagai boot device
  • Save & Exit

Step 3: Mulai Instalasi

  • Pilih "Graphical Install"
  • Pilih bahasa: English
  • Pilih lokasi: Indonesia
  • Pilih keyboard: American English

Step 4: Network & Hostname

  • Hostname: kali-choirus (atau bebas)
  • Domain: kosongkan saja

Step 5: Buat User Account

  • Full name: Muchamad Choirus Syafi'
  • Username: choirus
  • Password: buat password kuat
  • Konfirmasi password

Step 6: Partisi Disk

  • Pilih "Guided - use entire disk"
  • Pilih disk yang akan digunakan
  • Pilih "All files in one partition"
  • Konfirmasi "Write changes to disk" = Yes

Step 7: Tunggu Instalasi

  • Proses copy files (15-25 menit)
  • Jangan matikan komputer

Step 8: Package Manager

  • Network mirror: Yes
  • HTTP proxy: kosongkan

Step 9: Software Selection

  • Pilih desktop environment (Xfce recommended)
  • Centang tools yang diinginkan
  • Atau pilih "default" untuk semua tools

Step 10: Install GRUB Bootloader

  • Install GRUB: Yes
  • Pilih disk untuk GRUB

Step 11: Selesai!

  • Klik "Continue" untuk restart
  • Cabut USB saat diminta
  • Login dengan username & password
  • Selamat! Kali Linux sudah terinstall 🎉

Setelah Instalasi

Update Sistem

Buka Terminal dan jalankan:

  • sudo apt update
  • sudo apt upgrade -y
  • sudo apt dist-upgrade -y
Tips: Selalu update sistem secara berkala untuk mendapatkan tools dan security patches terbaru!
